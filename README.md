# BaseStonk docs

Mintlify-format documentation for [basestonk.io](https://basestonk.io).

## Local preview

```bash
npm i -g mint
mint dev
```

## Editing

- Facts (rates, addresses, mechanics) mirror the deployed contracts; if a
  number changes on-chain or in the app, it changes here in the same PR.
- The referral page states that codes earn and discount. It never lists
  per-depth percentages, tier names, or tier pricing.
